# Pocket-Money Analyzer

## Project Description

Pocket-Money Analyzer is a simple Python project designed to help students
analyze their pocket money and daily expenses.

The program takes the user's pocket money and details of five expenses.
It then analyzes the expenses and displays a final money report.

## Objectives

- To take pocket money as input from the user.
- To store expense categories and expense amounts.
- To calculate the total expense.
- To find the highest and lowest expense.
- To identify the category with the highest expense.
- To count expenses of ₹200 or more.
- To calculate the average expense.
- To calculate the remaining pocket money.
- To display expenses in ascending order.
- To provide a simple spending status.

## Features

The program can:

1. Accept the user's pocket money.
2. Accept five expense categories and their amounts.
3. Display all entered expenses.
4. Find the highest expense.
5. Find the lowest expense.
6. Find the category where the highest amount was spent.
7. Count expenses of ₹200 or more.
8. Calculate total spending.
9. Calculate remaining pocket money.
10. Calculate average spending.
11. Sort expenses from lowest to highest.
12. Display a final money report.
